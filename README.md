# Serverless Ticket Routing System

An enterprise-grade serverless application built with **Azure Functions (Python v2)** and **Apache Spark (PySpark)** to automatically triage, categorize, prioritize, and route customer support tickets.

## 🌐 Live Azure Endpoints
- **Health Check (`GET`)**: https://fn-ticket-router-elazar-01.azurewebsites.net/api/health
- **Ticket Routing API (`POST`)**: https://fn-ticket-router-elazar-01.azurewebsites.net/api/route_ticket
